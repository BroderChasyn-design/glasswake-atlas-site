# God Gathering mobile story build

Open this folder's index.html on a static HTTPS host. Add it to the phone's home screen while online; the service worker caches the game files for offline play after the initial download. Use landscape orientation. The RPG story collection is local-only and does not sync with the hosted card-game account. The title-screen online card-game option still opens the account-connected hosted game.

This release includes only assets referenced by the current RPG Maker database and active plugins. Regenerate it from the editor project with node build_mobile_release.js.
